# Подключение RSVP-формы к Google Sheets

Это нужно сделать один раз, руками, в вашем Google-аккаунте — я не могу зайти в ваш Google от вашего имени.

1. Создайте новую Google-таблицу на [sheets.google.com](https://sheets.google.com) — например, назовите её «Свадьба — ответы гостей».
2. В меню таблицы: **Расширения → Apps Script**.
3. Откроется редактор скрипта с пустым файлом `Code.gs`. Удалите содержимое и вставьте туда код из файла [`Code.gs`](Code.gs) рядом с этой инструкцией.
4. Сохраните (значок дискеты или Ctrl+S).
5. Нажмите **Развернуть → Новое развёртывание** (Deploy → New deployment).
   - Тип: **Веб-приложение** (Web app).
   - Кто имеет доступ: **Все / Anyone** (важно — иначе форма с сайта не сможет отправлять данные).
   - Нажмите **Развернуть**, разрешите доступ от своего аккаунта Google (запросит подтверждение — это нормально, скрипт ваш собственный).
6. Скопируйте появившийся **URL веб-приложения** — он выглядит так: `https://script.google.com/macros/s/AKfycb.../exec`.
7. Вставьте этот URL в файл [`../js/main.js`](../js/main.js) в самое начало, в константу:
   ```js
   const GOOGLE_SCRIPT_URL = "ВАШ_URL_СЮДА";
   ```
8. Готово — ответы из формы на сайте будут дописываться новой строкой в вашу таблицу.

**Если позже понадобится изменить скрипт:** после правки `Code.gs` в редакторе Apps Script нужно сделать **Развернуть → Управление развёртываниями → редактировать (иконка карандаша) → Новая версия → Развернуть** — иначе изменения не применятся к уже выданной ссылке.
